# Настройка

В начале `src/itmo-calendar.gs` находится объект `ITMO`:

| Поле | По умолчанию | Назначение |
| --- | --- | --- |
| `name` | `Учёба ИТМО` | Имя при создании календаря |
| `days` | `28` | Число дней в окне синхронизации |

Изменение `name` не переименует уже созданный календарь. Его можно переименовать в Google Календаре. При увеличении окна учитывайте квоты и ограничения API. Сообщение предпросмотра содержит фиксированное число 28: при изменении окна поправьте и его.

Часовой пояс используется в нескольких местах кода. Для расписания ИТМО оставьте `Europe/Moscow` и смещение `+03:00`; интерфейс календаря сам показывает события в часовом поясе пользователя.

| Функция | Действие |
| --- | --- |
| `previewItmo` | Получить и показать расписание без записи событий |
| `startItmoSync` | Перенести занятия и включить часовой запуск |
| `syncItmo` | Однократно обновить календарь |
| `stopItmoSync` | Удалить триггеры этой синхронизации |

Служебные свойства `ITMO_CALENDAR_ID`, `PREVIEW_OK_AT`, `LAST_SUCCESS`, `LAST_ERROR` ведёт скрипт. Не удаляйте ID для переименования: иначе следующий запуск создаст ещё один календарь.

Уведомления новых событий зависят от настроек календаря. При отмене уведомления события удаляются. Скрипт помечает только свои события и не обрабатывает вручную добавленные записи без служебных тегов.
