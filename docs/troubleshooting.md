# Если что-то не работает

Сначала откройте раздел выполнений проекта Apps Script. В свойствах `LAST_SUCCESS` показывает последний успешный запуск, `LAST_ERROR` — наличие сбоя. Не публикуйте полный журнал без проверки на личные данные.

| Ситуация | Что проверить |
| --- | --- |
| Нет данных для входа | Оба свойства `ITMO_USERNAME` и `ITMO_PASSWORD` сохранены |
| Вход не завершён | Проверьте вход вручную в My ITMO; дополнительный фактор или изменённая форма могут не поддерживаться |
| Сначала выполни previewItmo | Повторите предпросмотр и запустите синхронизацию в течение часа |
| Расписание пустое | Проверьте окно дат и My ITMO; календарь сохранён намеренно |
| Резко уменьшилось число занятий | Сверьте источник; автоматические массовые отмены блокируются |
| Календарь недоступен или изменён | Проверьте аккаунт, права владельца и описание календаря; не удаляйте ID вслепую |
| Ошибка квот Google | Посмотрите конкретную ошибку выполнения и дождитесь восстановления квоты |
| Занятия не появляются на iPhone | Проверьте Google-аккаунт, включение календарей и выбор «Учёба ИТМО» |

Не меняйте защиту массовых отмен, пока не выясните причину сокращения ответа. Не переносите пароль в код для исправления ошибки входа.

Если сообщаете об ошибке в Issues, укажите этап, обезличенное сообщение, дату и ожидаемое поведение. Для примера используйте вымышленные занятия и данные.
